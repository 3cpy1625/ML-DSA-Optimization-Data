# 字段与计数口径

## 定位一条结果

1. 在 [结果 CSV](../results/views/) 或 [Excel](../results/summary.xlsx) 中找到“来源ID”。
2. 在 [来源索引](../data/metadata/) 中查找对应的“来源包”和“包内路径”。`!` 或 `!/` 表示嵌套归档层级。
3. 先读来源索引的“材料保留状态”和“仓库文件”：随包提供的证据可直接打开；派生表应结合其生成来源解释；“仅保留来源定位”表示该原文件没有收录。通过表索引的原始／派生标记、SHA256 和存储路径找到随包表文件。原始表位于 `data/raw/tables/`，派生表位于 `data/derived/tables/`。
4. 使用“源行号”或“JSON定位”回到相关记录。CSV 含多行字段时，源行号沿用提取时记录的物理行位置，不能直接等同于数据记录序号。

来源ID是发布版内的交叉引用标识。SHA256识别文件字节；相同SHA256的多个路径代表同内容副本，不代表多次测量。

## 表索引

- 原始／派生标记：区分原 ZIP 中存在的表文件与整理时提取生成的表。
- 有无表头：显式记录原表的表头属性。无表头时，第一行仍为数据，不擅自改成字段名。
- 数据行数：按 CSV/TSV 解析所得的数据记录数；有表头时不包含表头，无表头时首行也是数据。
- 字段数、最小/最大宽度与列宽模式：来自原始表的解析结果，不包含整理过程添加的源行号等辅助列。固定宽度表可用单一字段数描述；宽度不一致的表须同时查看最小、最大宽度和列宽模式，不能用零表示未知，也不能把字段数误作数据行数。
- SHA256：随包表内容的字节校验值。原始表保留原编码和换行，因此只改变换行的两个文件也可能具有不同值。
- 同内容路径数：指向同一内容的来源路径数，不是独立实验数。

## 主性能

- `结果系列`、`GPU`、`参数集`、`操作`、`批量`、`消息字节`：定义可比较的结果单元。不同系列不得仅因参数相同而直接合并。
- `本项目耗时_ms`、`cuPQC耗时_ms`：整批耗时，单位毫秒；`耗时归约方法`说明取均值或中位数。
- `配对几何加速比_x`：每对进程的对照耗时除以本项目耗时，再取几何均值。大于 1 表示本项目在该比较中更快。
- `CI95下界_x`、`CI95上界_x`：仅在来源提供且方法可追溯时填入。空白不是零，也不表示零不确定性。
- `观测配对最小_x`、`观测配对最大_x`：已观测配对比值的范围，不是置信区间。
- `配对区组数`、`每进程计时次数`：分别描述进程配对与进程内重复，不能相乘后解释为独立语料数。
- `数据状态`、`比值方向`、`计时范围`：保留替换复测、固定配置、设备驻留和计时边界。

## 消融、微基准和辅助诊断

`对照分子`与`候选分母`决定倍率方向。OFF/ON、W1/W3 和 P0/R1/C1 是不同实验对照；同二进制漂移对照不等于关闭优化后的消融。

`指标原名`、`值`、`单位`保留指标含义。单位为“原指标单位”时，应回查来源，不能自行推定为毫秒、次数或倍率。`重复数`与`重复单位`共同解释观测层级。

辅助诊断包括资源、阶段计时、工作空间、故障恢复和版本身份等信息。不能把该页所有数值都作为主性能或全部相加。

## 正确性记录

`记录层级`、`计数单位`、`分类依据`说明一行代表什么。工具过程、单项或变体输出检查、恢复阶段、身份核验、汇总及未运行项分别保留。分类依据来自可追溯的来源字段或原记录内容；分类说明本身是整理元数据。

本版使用12种层级：用例汇总、工具进程、截图记录、进程输出汇总、进程用例、子项检查、进程最终输出、停止阶段汇总、变体检查、未执行项、恢复阶段、身份核验。应与同一行的“计数单位”和“分类依据”一起读取。即使分类相同也不能直接去重：171条工具进程记录中包含4090补测沿用的59项结果，不表示171次新增独立工具运行。

`状态`保留原记录结论。PASS只适用于本行工具、输入和二进制的检查范围；`NOT_RUN`、`SKIPPED`、停止和警告不转成PASS。一次工具过程中的多个子项检查不能重复计入工具运行次数。

`报告错误数`、`拒绝数`与备注中的工具警告数属于不同指标，不能互相替代。零错误不等于零告警；无值不补零。4090 修补前的147,462条racecheck告警及修补后的资格结果分别保留。

## 实验导航

实验目录新增 `GPU`、`数据轮次`、`实验类别`、`原始运行标识`、`运行标识依据`、`相关来源ID集合`、`来源关联说明`。导航按GPU、来源轮次和实验系列组织；各轮次的分类CSV提供另一个检索入口。设备和轮次用于检索；运行标识应回到来源核对，不能把导航用的目录名当作新生成的实验事实。

原始运行标识优先采用来源JSON中的 `run_id`，其次采用原路径中的完整时间戳目录名。目录中的时间戳不直接被解释为实验采集日期；无法确定时留空并说明依据。本版60条实验目录记录中，12条没有明确运行标识，不根据ZIP包名补造。

一个实验可能关联多份表和日志。`相关来源ID集合`保留这些关系；只看单个来源ID可能不足以覆盖整个实验。旧版来源引用的修正单独留痕，不改原始文件。

## 空值与文件格式

展示表中的空值表示未提供、缺失或不适用，具体含义以状态和备注为准。原始表中的空字符串、零和其他原文保持原样。CSV/TSV 的展示编码与原始字节编码不必相同。

部分原始证据虽以 `.json` 结尾，实际内容是异常回溯文本。扩展名保留原貌，读取时需核对内容，不能把解析失败直接判为整理损坏。
